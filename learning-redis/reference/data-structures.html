Gotchas

  • A string value can be up to 512 MB.
  • SET on an existing key replaces the value and clears its TTL.
  • SISMEMBER then SADD is a check-then-act race. Use SADD's return value instead.
  • Pub/Sub messages sent while a subscriber is disconnected are lost. Source
