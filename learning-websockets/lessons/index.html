The real-time socket layer

From the bytes on the wire to a socket layer that can carry Excalidraw, Gather Town, a crypto exchange or a multiplayer game.

Part I starts with the protocol (0001–0003), then switches to building: from 0004 on, every lesson is a build-along with a reference solution in labs/ and an automated check suite you run against your own server in ~/learning-websockets/build/. Tick lessons off as you finish them.
