Socket backend patterns

Envelope & errors (0004)

client → { type, id?, data? }
server → { type:"ack", id, data }
       | { type:"error", id?, data:{ code, message } }
       | { type, seq?, data }            // events
codes: bad_json bad_envelope unknown_type invalid
       forbidden limit rate_limited internal

Bad message → error, keep the socket. Abuse → close 1008. Name types noun.verb. No id on high-frequency traffic.

Upgrade checklist (0005–0006)

1 Origin in allowlist?        else 403
2 token valid, not expired?   else 401   (identity = token.sub)
3 params valid (room id)?     else 400
4 capacity ok?                else 503
5 draining?                   else 503
6 server.upgrade(req, { data })

Join order

single node:  snapshot → subscribe          (open is sync)
multi node:   subscribe → snapshot          (client buffers seq'd events
                                             until snapshot, drops seq ≤ snap.seq)

Resume (0006)

reconnect ?lastSeq=N&epoch=E
resume if  E == room.epoch  &&  oldestLogSeq−1 ≤ N ≤ room.seq
else       full room.state
client:    apply only seq > lastSeq (dedupe)

Client reconnect

delay = random(0, min(10s, 0.5s × 2^attempt))   // full jitter
reset attempt on open · 4001 → refresh token, retry now
app-level ping every 10s, 5s timeout → close → reconnect

Backpressure (0007)

ws.getBufferedAmount()  (Bun)   ws.bufferedAmount (ws/browser)
SOFT 64 KB  → skip ephemeral for that socket
HARD 1 MB   → ws.terminate()  (not close: frame queues behind backlog)
backpressureLimit > HARD      (past it Bun DROPS silently)
cursors: coalesce per user, flush one batch per room per tick

Order books (0011)

subscribe diffs → buffer → GET snapshot
snapshot.id < firstU−1 → refetch
drop buffered u ≤ id → apply rest → live
live: U > id+1 → GAP → resync · qty "0" → delete level
rate limit: token bucket per socket, close 1008
