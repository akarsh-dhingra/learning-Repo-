Server API: Bun vs Node + ws

Bun: full skeleton

type Data = { userId: string; room: string };

const server = Bun.serve({
  port: 8080,
  fetch(req, server) {
    const url = new URL(req.url);
    // auth + Origin checks HERE, before upgrade
    const ok = server.upgrade(req, {
      data: { userId: "u1", room: url.searchParams.get("room") ?? "lobby" },
    });
    if (ok) return;               // no Response after upgrade
    return new Response("Upgrade required", { status: 426 });
  },
  websocket: {
    data: {} as Data,             // types ws.data
    open(ws)               { ws.subscribe(ws.data.room); },
    message(ws, msg)       { ws.publish(ws.data.room, msg); },
    close(ws, code, why)   { /* auto-unsubscribed */ },
    drain(ws)              { /* buffer emptied: resume */ },
    idleTimeout: 120,             // s, default 120; 0 = off
    maxPayloadLength: 16 * 1024 * 1024,   // default; over → 1009
    backpressureLimit: 16 * 1024 * 1024,  // default
    perMessageDeflate: false,
  },
});

Node + ws: same server

import http from "node:http";
import { WebSocketServer } from "ws";

const httpServer = http.createServer((req, res) => res.end("ok"));
const wss = new WebSocketServer({ noServer: true });
const rooms = new Map();          // room → Set<ws> (no built-in topics)

httpServer.on("upgrade", (req, socket, head) => {
  // auth + Origin checks HERE; on failure:
  // socket.write("HTTP/1.1 401 Unauthorized\r\n\r\n"); socket.destroy();
  wss.handleUpgrade(req, socket, head, (ws) => {
    ws.room = new URL(req.url, "http://x").searchParams.get("room") ?? "lobby";
    if (!rooms.has(ws.room)) rooms.set(ws.room, new Set());
    rooms.get(ws.room).add(ws);
    ws.on("message", (data, isBinary) => {
      for (const peer of rooms.get(ws.room))
        if (peer !== ws) peer.send(data, { binary: isBinary });
    });
    ws.on("close", () => rooms.get(ws.room).delete(ws));
  });
});
httpServer.listen(8080);

Heartbeats aren't automatic in ws. Use ws.ping() on an interval and terminate sockets that didn't answer with a pong (see the ws README). Backpressure: check ws.bufferedAmount.

Client (browser, Node ≥ 22, Bun)

const ws = new WebSocket("wss://host/?room=abc");
ws.binaryType = "arraybuffer";
ws.onopen    = () => ws.send(JSON.stringify({ type: "hello" }));
ws.onmessage = (e) => console.log(e.data);
ws.onclose   = (e) => console.log(e.code, e.reason);
ws.readyState   // 0 CONNECTING 1 OPEN 2 CLOSING 3 CLOSED
ws.bufferedAmount // bytes queued, not yet sent
